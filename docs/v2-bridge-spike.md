# OMO on OpenCode v2: bridge spike

The bridge runs current OMO on real OpenCode 2.2.7: the plugin is active, all 11 OMO agents register, Sisyphus receives its resolved dynamic prompt, OMO tools and four MCP definitions register, and a real model/tool/model turn completes. Native fills additionally prove skill permission allow/reject, todo continuation and stop, and rule/mode/compaction instruction delivery. The delegation increment proves configured child model/preset authority, injected skills, foreground and background results, and retained launcher denies on vt15. Native task ownership and several SDK-dependent recovery paths remain separate work.
